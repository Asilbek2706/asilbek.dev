# 🚀 My Portfolio

Ushbu loyiha zamonaviy va xavfsiz muloqot tizimi bo'lib, foydalanuvchilarga "Cyberpunk" stilidagi interfeys orqali admin bilan bog'lanish imkonini beradi. Tizim reCAPTCHA v3 himoyasi va real-vaqtda ma'lumotlarni yangilash funksiyalari bilan jihozlangan.



## ✨ Xususiyatlari

- **Invisible Security:** Google reCAPTCHA v3 yordamida botlardan 100% himoyalangan forma.
- **Glassmorphism UI:** Shaffof va animatsiyalarga boy dizayn (SCSS Modules).
- **Reactive Data:** TanStack Query (React Query) yordamida savollar sonini va ro'yxatini real-vaqtda yangilash.
- **Smooth Navigation:** Sahifalararo silliq o'tish va savollar arxivi.
- **Responsive Design:** Mobil qurilmalar va keng ekranlar uchun mukammal moslashuvchanlik.

## 🛠 Texnologiyalar (Stack)

- **Core:** React 18, TypeScript
- **State & Data Fetching:** TanStack Query (v5)
- **Security:** Google reCAPTCHA v3
- **Styling:** SCSS Modules, Bootstrap Icons
- **Routing:** React Router DOM v6
- **HTTP Client:** Axios
