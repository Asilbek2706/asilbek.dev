Bu shunchaki portfolio emas, bu Manga va Komiks olamidan ilhomlangan, yuqori darajadagi interaktivlikka ega raqamli tajriba. Loyiha zamonaviy texnologiyalar va Brutal dizayn prinsiplarini birlashtiradi.

---

## 🎨 DIZAYN KONSEPSIYASI (THE VIBE)

Loyihaning vizual tili quyidagi elementlarga asoslangan:
* **Halftone Patterns:** Klassik manga bosma uslubidagi nuqtali fonlar.
* **Heavy Borders:** Qalin qora chiziqlar va keskin soyalar.
* **Speed Lines:** Dinamik harakatni ifodalovchi chiziqlar va animatsiyalar.
* **Typography:** 'Bebas Neue' va 'JetBrains Mono' kabi agressiv va aniq shriftlar.

---

## 🛠 TEXNIK STACK (THE ARSENAL)

| Texnologiya | Vazifasi |
| :--- | :--- |
| **React 18** | UI Komponentlar arxitekturasi |
| **TypeScript** | Qat'iy tiplashtirish va xavfsiz kod |
| **TanStack Query** | Server state boshqaruvi va API kesh |
| **Sass (SCSS)** | Murakkab manga animatsiyalari va mixinlar |
| **Vite** | Chaqmoqdek tez build jarayoni |
| **Zustand** | Yengil va samarali global state boshqaruvi |

---

## 🚀 ASOSIY FUNKSIYALAR

* 📇 **Manga Loader:** Tizim ishga tushishini anglatuvchi dinamik preloader.
* 🖼 **Project Archive:** Galereya uslubidagi loyihalar ro'yxati (Brutal Cards).
* 📩 **Contact System:** reCAPTCHA v3 bilan himoyalangan xabarlar yuborish tizimi.
* ⚡ **Scroll Magic:** Sahifalar almashganda skrollni avtomatik boshqarish (ScrollToTop).
* 📱 **Responsive Panels:** Har qanday ekran o'lchamida komiks panelidek moslashuvchan dizayn.

## 🛠 O'RNATISH (GETTING STARTED)

Lokal muhitda ishga tushirish uchun:

1.  **Loyiha kloni:**
    ```bash
    git clone [https://github.com/Asilbek2706/asilbek.dev.git](https://github.com/Asilbek2706/asilbek.dev.git)
    ```
2.  **Kutubxonalarni o'rnatish:**
    ```bash
    npm install
    ```
3.  **Lokal serverni yoqish:**
    ```bash
    npm run dev
    ```

## ⚠️ MUHIM ESLATMALAR

* **API Connection:** Loyiha backend API bilan ishlaydi. 403 (Forbidden) xatoligi yuz bersa, CORS sozlamalarini tekshiring.
* **Environment Variables:** `.env` faylingizda `VITE_RECAPTCHA_SITE_KEY` mavjudligiga ishonch hosil qiling.
